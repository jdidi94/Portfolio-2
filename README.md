# Neon Portfolio

Immersive 3D portfolio experience (React · R3F · GSAP · Zustand).

## Docs

See [documentation/README.md](documentation/README.md).

## Develop

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

Controls: click an orb to travel · click empty space or Esc to explore · ← → cycle · M toggles audio (no audio files yet — safe no-op).

## Build

```bash
npm run build
npm run preview
```

## Current phase

Phase 1 foundation + Phase 2 experience engine (placeholder orbs, cinematic camera, interaction, atmosphere). Portfolio content arrives in Phases 3–4.
