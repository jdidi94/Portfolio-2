# 3D Models

GLB assets for the Neon Portfolio scene.

**Role, placement, and design rules:**  
[documentation/MODELS_3D_README.md](../../../documentation/MODELS_3D_README.md)

| Folder | Role |
|--------|------|
| `cards/` | Content frames (empty face for portfolio cards) |
| `props/` | Decorative accents in the void |
| `environment/` | Scene anchors (platforms, light bars) |
| `player/` | Rigged About Me character (preserve materials) |

Register new files in `src/config/assets.ts`. Do not hardcode URLs in mesh components.
